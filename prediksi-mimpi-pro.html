🚀 Cara Jadi APK
1Download 4 file di atas (icon 192, icon 512, manifest, sw)
2Taruh SEMUA file + index.html dalam 1 folder
3Buka app.netlify.com/drop
4Drag SEMUA 5 FILE sekaligus ke Netlify
5Dapat URL .netlify.app → buka di browser (test dulu)
6Paste URL ke pwabuilder.com → Android → APK 🎉
